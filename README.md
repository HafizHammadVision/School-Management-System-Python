# School Management System

A console-based School Management System developed in Python using Object-Oriented Programming.

## Features
- Student Management
- Teacher Management
- Marks Management
- Student Report Cards
- Top Performing Student Report
- Failed Student Report
- File Handling
- Exception Handling
- Menu Driven Interface

## Concepts Used
- Classes and Objects
- Lists
- Dictionaries
- CRUD Operations
- File Handling
- Exception Handling
- OOP
